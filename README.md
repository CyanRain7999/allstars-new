# 全明星归来

为个人游玩制作的《植物大战僵尸：全明星》同人复刻。主页采用浮岛、九世界入口与每日活动布局；主线采用老版世界顺序和关卡数量。保留三路战斗、六株固定植物加一株跨路板车、职业技能豆与植物养成。界面为重绘，剧情、战斗配置与抽卡数值为重建，尚未达到原客户端逐像素、逐脚本一致。

双击 **启动游戏.cmd** 或 **index.html** 就能开始。全部素材已经保存在 assets，不需要联网、注册或安装依赖。推荐用桌面版 Edge / Chrome。移动端也能打开，但键盘快捷键仅适用于电脑。

如果希望通过本地服务器游玩：安装有 Node.js 的电脑在目录内执行 `npm start`，打开 http://127.0.0.1:4173 。通过文件直接打开与本地服务器打开属于不同的浏览器存档位置，请使用存档导出 / 导入转移进度。

上传在线版请看 **[上传在线版.md](上传在线版.md)**；已经配好 GitHub Actions → GitHub Pages 和可安装、离线游玩的 PWA。上传包包含 `.github`，解压时保留该目录。

## 当前可玩内容

- 老版九世界：美国小镇 15 关、原始部落 20 关、万里长城 25 关、神秘埃及、海盗湾、狂野西部、功夫世界、西游记、维京世界各 30 关，共 240 关。每五关有首领战，通关整个世界开启下一世界。
- 36 种植物，初始只拥有豌豆射手、向日葵与坚果。主线 1-1、1-3、1-5 首通分别赠送卷心菜投手、寒冰射手与菜问。其余通过抽卡或碎片合成获得。前三关逐步开放路线。
- 友情召唤与钻石召唤，支持单抽 / 十连。友情 R/SR/SSR 概率 80% / 19% / 1%；钻石为 60% / 32% / 8%。十连至少一位 SR+，钻石召唤 30 抽内必得 SSR。游戏内可查看完整规则与最近 30 次记录。
- 友情每天 3 次免费机会，间隔 10 分钟；钻石每 48 小时一次免费。钻石单抽 280，十连 2,520。每日签到、任务、主线首通和星星奖励提供货币。
- 重复卡提供专属碎片（R 8 / SR 16 / SSR 32），用于进化，也能 8 换 4 万能碎片；未拥有的 R / SR / SSR 分别用 40 / 100 / 240 万能碎片合成。
- 植物使用 PvZ2 Gardendless 的原生 DragonBones 骨骼动画，在战场与花园播放待机动作；战斗按植物已有动作切换发射、抛射、拳击、治疗、必杀与死亡。没有相应动作的原生植物会继续待机，例如坚果没有射击动作。
- 豌豆、寒冰豌豆、火焰豌豆、卷心菜、玉米 / 黄油、西瓜 / 冰瓜、回旋镖、杨桃、椰子、能量球、电豌豆等使用原生弹体骨骼与贴图。发射延迟从动画事件帧读取，发射位置跟随原生口部或投手手部。豌豆实际穿过火炬后才转成火焰弹；治疗植物不会射出替代圆点。
- 重新铺设三路、七列的战场，每路前两格为固定植物位置，右侧为僵尸行进区，左侧是可跨路移动的板车。格子和种植点击范围使用同一套坐标。
- 植物列表支持按职业筛选和名称搜索。新增穿透、抛射、黄油定身、范围溅射、灼烧、闪电连锁、回旋镖往返、三路齐射、再生与全息护盾等战斗机制。
- 6 个固定位置与 1 株板车植物；同一种植物不能重复上阵。
- 自动攻击，职业技能豆（最多 8 颗），手动 / 自动必杀，治疗、冻结、击退、护盾与羁绊。
- 金币升级（最高 60 级）与精华、专属碎片进化（最高 6 星）。首次与重复通关奖励不同。
- 无尽挑战、1 / 2 / 3 倍速、暂停、合成音效、自动存档、JSON 存档导入 / 导出。

操作：选植物后点击位置；同一植物换位会交换已有植物；无植物选中时再次点击已选位置可移除。战斗时点击技能卡释放必杀。方向键上下移动板车，数字键 1–7 释放技能，空格暂停，A 自动技能，S 倍速。

存档保存在当前浏览器。清理浏览器数据之前请点右上角齿轮导出存档。导入会先要求确认替换当前进度。

新版使用独立的 v2 存档，新开局仅三株。v1 存档保留，主页与存档菜单可恢复；旧版的埃及、海盗关卡映射到对应的新世界，已有植物、金币、等级、星级与阵容保留。恢复、导入或重新开始之前会自动备份当前新版存档。

PWA 首次打开需要联网下载离线资源，准备完毕后导航栏显示“可离线游玩”。新版本不会在战斗中强制刷新，收到提示后可在齿轮菜单更新。所有路径相对部署目录，支持 `用户名.github.io/仓库名/`。

开发：`npm start` 开本地服务器；`npm test` 跑关键回归；`npm run build` 生成 `dist` 和资源版本清单。构建不需要 npm install。`research`、离线包、预览图和 `dist` 都已从 Git 上传中排除。

## 素材与参考

36 种植物的骨骼、关键帧和贴图来自 [PvZ2 Gardendless 网页版公开资源](https://github.com/Gzh0821/pvzge_web)，保持原资源动作并接入本地 Canvas；卡片透明图由这些原生动画的待机姿态渲染生成。逐植物来源记录在 `assets/animations/sources.json`。草坪纹理来自 [Gardendless 资料网站](https://github.com/Gzh0821/pvzg_site)。僵尸部件来自 [江南游戏 PVZ2PAK](https://github.com/jiangnangame/PVZ2PAK)，僵尸动作在本项目中用 Canvas 部件组合实现。

骨骼运行库为 [DragonBonesJS](https://github.com/DragonBones/DragonBonesJS) 的官方核心，MIT 许可与版权声明保存在 `vendor/dragonbones-core.js` 中。本项目的 Canvas 适配层为 `animation.js`。不同植物原生动作数量有所差别，未制作原作不存在的动作。

PvZ 名称、角色与游戏美术的权利归原权利人 EA / PopCap 所有。本项目定位为本地个人游玩的非官方同人复刻。程序、关卡和界面是本项目自行实现。

世界顺序、关卡数量、召唤入口参考 [All Stars 资料归档](https://plantsvszombies.fandom.com/wiki/Plants_vs._Zombies:_All_Stars)。战斗场景沿用 PvZ2 草坪、沙地、甲板三种地面纹理，九世界的浮岛图标与地图配色独立重绘。僵尸目前仍为部件组合动画；装备、联网竞技与社交尚未实现。

验证：`npm test` 检查三株开局与前六关递进、首通奖励、召唤扣费与保底、免费间隔、碎片合成进化、存档迁移、动画发射时机、36 种骨骼动画及 PWA 文件与相对路径。`assets/projectiles/data.js` 的原生豌豆与火焰弹同样来自 Gardendless 公开资源。
